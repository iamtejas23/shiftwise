Each festival illustration in this folder is a separate, individually
generated transparent PNG for Shiftwise. No festival icon is cropped from a
shared image sheet. The PNGs use a consistent 192 x 192 canvas and are bundled
locally for offline use.

ganesha.png is a dedicated Ganesh Chaturthi illustration generated for the
Ganesh Chaturthi preset. Every other named festival PNG is also generated as
its own standalone image.

2728.png (sparkles) is a Twemoji PNG asset from jdecked/twemoji v17.0.1:
https://github.com/jdecked/twemoji/tree/v17.0.1/assets/72x72
